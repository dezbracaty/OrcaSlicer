# Continuous-fiber models

These STL files are shared inputs for manual slicing and the full-model CTest
cases in `tests/libslicer_api/CMakeLists.txt`. The 4xiao and 7xiao models are
each sliced with 1, 2, 3, and 4 fiber contours. Bracket1 is used by the resin
regression and its configuration remains in `tests/data/continuous_fiber/bracket1`.
